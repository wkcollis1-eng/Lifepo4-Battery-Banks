Usable Capacity Validation

The 12V 500Ah battery bank delivers 397 Ah (99.3%) usable capacity via controlled discharge test.

🔬 Analysis Methods
Capacity Calculation
Capacity (Ah) = ∫ Current(A) × dt (hours)
Constant 20A discharge load until 10.8V cutoff

Integration Script analysis/capacity_integration.py

Voltage Drift Rate (Full Stasis)
Claim 3
During 70-day stasis period, bus voltage drifted at −0.67 mV/day with high linear correlation (R² > 0.95).
📊 Data Sources
Stasis Period Voltage data/voltage_stasis_oct29-jan06.csv
Days 1-70 (Oct 29, 2025 – Jan 6, 2026)
🔬 Analysis Methods
Linear Regression
V(t) = β₀ + β₁·t + ε
Slope (β₁) = drift rate in mV/day
R² calculated to assess fit quality
MA-60s Filtering
60-sample moving average applied
Reduces high-frequency noise before regression
💻 Code/Scripts
Drift Analysis analysis/drift_regression.py
Scipy linear regression + R² calculation
Late-Stage Drift Reduction
Claim 4
Drift rate decreased 75% from full-period average (−0.67 mV/day) to last-30-day rate (−0.17 mV/day), indicating approach to equilibrium.
📊 Data Sources
Full Period Data data/voltage_stasis_oct29-jan06.csv
Days 1-70 for baseline drift
Late Period Data data/voltage_late_jan01-jan31.csv
Last 30 days of study
🔬 Analysis Methods
Segmented Regression
Separate linear fits for each period
Comparison of slope magnitudes
Percent Change
Reduction = (old_rate - new_rate) / old_rate
(−0.67 − (−0.17)) / −0.67 = 75%
Interpretation: Slower drift suggests battery approaching electrochemical equilibrium. Supports long-term storage viability claim.
Storage Endurance Projection
Claim 5
Based on late-period drift rate (−0.17 mV/day), battery can remain in storage for 7-10 months before reaching 80% SOC (~13.0V).
📊 Data Sources
Current Voltage State data/voltage_final_jan31.csv
End-of-study voltage: ~13.35V
Late Drift Rate analysis/drift_last30days_results.json
−0.17 mV/day from regression
🔬 Analysis Methods
Linear Projection
Days = (V_current - V_target) / drift_rate
(13.35V - 13.0V) / 0.00017 V/day ≈ 210-300 days
Equivalent Current
Self-discharge ~13-20 mA equivalent
Calculated from drift and capacity
Key Assumptions:
  • Drift rate continues at late-period trend (conservative)
  • 80% SOC ≈ 13.0V for LiFePO₄ (chemistry-dependent)
  • No external load or temperature extremes
Temperature Coefficient
Claim 6
System-level temperature coefficient of +1.0 ± 0.3 mV/°F observed across 34-day analysis period.
📊 Data Sources
Temperature Data data/temperature_dec28-jan30.csv
Ambient temperature (34-day subset)
Voltage Data data/voltage_dec28-jan30.csv
Synchronized voltage readings
🔬 Analysis Methods
Correlation Analysis
Pearson correlation: r = cov(V,T) / (σ_V · σ_T)
Linear Regression
V = β₀ + β₁·T
Slope (β₁) = temperature coefficient
💻 Code/Scripts
Temperature Correlation analysis/temp_correlation.py
Scipy correlation + regression analysis
Limitation: Ambient temperature only (not battery core). Coefficient includes both cell chemistry and measurement chain thermal effects.
MA-60s Noise Reduction
Claim 7
60-sample moving average (MA-60s) filter achieved 42-50% noise reduction depending on segment regularity.
📊 Data Sources

🔬 Analysis Methods
Noise Quantification
σ_raw = standard deviation of raw signal
σ_MA60s = standard deviation of filtered signal
Reduction Calculation
Reduction = 1 - (σ_MA60s / σ_raw)
Calculated per segment (stasis vs eco)
