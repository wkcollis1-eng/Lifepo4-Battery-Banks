# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

---

## Our Standards

### ✅ Positive Behaviors

| Behavior | Description |
|:---------|:------------|
| **Welcoming language** | Use inclusive, respectful communication |
| **Respect** | Value differing viewpoints and experiences |
| **Graceful acceptance** | Accept constructive criticism professionally |
| **Community focus** | Prioritize what's best for the community |
| **Empathy** | Show understanding toward other community members |
| **Knowledge sharing** | Help newcomers and share expertise openly |

### ❌ Unacceptable Behaviors

| Behavior | Description |
|:---------|:------------|
| **Harassment** | Trolling, insults, derogatory comments, personal attacks |
| **Privacy violations** | Publishing others' private information without permission |
| **Inappropriate conduct** | Other behavior that would be inappropriate in a professional setting |

---

## Our Responsibilities

Project maintainers are responsible for:

- Clarifying standards of acceptable behavior
- Taking appropriate and fair corrective action in response to unacceptable behavior
- Removing, editing, or rejecting contributions that violate this Code of Conduct
- Temporarily or permanently banning contributors for inappropriate behavior

---

## Scope

This Code of Conduct applies within all project spaces, including:

| Space | Examples |
|:------|:---------|
| **GitHub** | Repository, issues, PRs, discussions |
| **Communications** | Project-related emails, messages |
| **Public representation** | Speaking at events, social media posts about the project |

---

## Enforcement

### Reporting

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported by:

1. **Opening an issue** (for non-sensitive matters)
2. **Contacting the project owner** via GitHub direct message (for sensitive matters)

### Process

All complaints will be:
- Reviewed promptly
- Investigated fairly
- Kept confidential as appropriate

### Consequences

Depending on severity, consequences may include:

| Level | Action |
|:------|:-------|
| **Warning** | Private written warning |
| **Temporary ban** | Temporary exclusion from project spaces |
| **Permanent ban** | Permanent exclusion from project spaces |
